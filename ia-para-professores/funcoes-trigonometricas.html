Funções trigonométricas

Mexa nos parâmetros a, b, c e d e veja o que cada um faz com o gráfico. A curva cinza é a função original, sem parâmetros, para comparar.

f(x) = a + b·sen(c·x + d)

Parâmetros

Soma um valor a toda a função.
Multiplica o resultado do seno ou do cosseno.
Multiplica o x, dentro da função.
Soma um valor ao ângulo, dentro da função.

Com os valores de agora

f(x) sen(x), a função original (a = 0, b = 1, c = 1, d = 0) um período de f
