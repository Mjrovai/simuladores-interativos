O que isso tem a ver com o ChatGPT?

É a mesma ideia: prever a próxima palavra. A diferença é de escala. Esta máquina olha 1 a 3 palavras para trás e leu — palavras. Um modelo de linguagem grande olha para centenas de milhares de palavras para trás e leu trilhões. Por isso escreve tão bem e por isso também inventa com a mesma segurança: ela não consulta fatos, ela escolhe a continuação mais provável.

  • Temperatura 0: sempre a palavra mais provável. Repetitivo, previsível.
  • Temperatura alta: arrisca palavras raras. Mais "criativo", mais sem sentido.
  • Olhar 3 palavras para trás: frases mais coerentes, mas começa a copiar o texto original. É o problema da memorização.
