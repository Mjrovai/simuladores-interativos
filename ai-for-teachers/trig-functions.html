The request that generated this simulator 
Create an interactive simulator in a single HTML file (HTML, CSS, and JavaScript together, no external libraries and no server), in English. Reply only with the complete code, in a single block, from <!DOCTYPE html> to </html>, without using Python and without creating files.

TOPIC: [trigonometric functions: f(x) = a + b·sin(c·x + d)]
FOR WHOM: [11th grade] students, subject [Mathematics].
WHAT THE STUDENT CAN CHANGE: [sliders for a, b, c, and d, and a button to switch between sine and cosine].
WHAT APPEARS ON SCREEN: [the graph of f(x) from −2π to 2π, the graph of sin(x) in gray for comparison, and the calculated amplitude, period, and range].
QUESTION THE SIMULATOR HELPS ANSWER: [what does each parameter do to the graph? Which one changes the period?]
EXTRAS: a "Reset" button, the x axis marked in multiples of π, large fonts for projecting in class.
