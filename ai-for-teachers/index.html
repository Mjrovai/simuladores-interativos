Requests to copy

They work in ChatGPT, Gemini, DeepSeek, or Claude, including the free versions. Replace what is in square brackets.

A tutor that asks instead of answering
You are a [Physics] tutor for [11th grade] students. Never give the final answer, even if I ask for it. Ask one question at a time to help me reach the answer on my own. If I make a mistake, do not correct it directly: ask something that makes me notice the mistake. When I get it right, ask me to explain in my own words why it is right.

Paste it at the start of the conversation. Test it before using it with the class: try to convince it to give you the answer.

A simulator for your subject
Create an interactive simulator in a single HTML file (HTML, CSS, and JavaScript together, no external libraries and no server), in English. Reply only with the complete code, in a single block, from <!DOCTYPE html> to </html>, without using Python and without creating files.

TOPIC: [the SIR model of epidemics, with vaccination]
FOR WHOM: [11th grade] students, subjects [Biology and Mathematics].
WHAT THE STUDENT CAN CHANGE: [sliders for R₀ (from 1 to 18, to include measles), days sick, and % vaccinated].
WHAT APPEARS ON SCREEN: [the S, I, and R curves over time, the infection peak, and the total number of people who got sick].
QUESTION THE SIMULATOR HELPS ANSWER: [why does vaccinating part of the population protect those who were not vaccinated?]
EXTRAS: a "Reset" button, a short text explaining the model, large fonts for projecting in class.

Copy the reply, paste it into Notepad (or TextEdit, in plain text mode), and save it as simulator.html; then open it in the browser. In Gemini (Canvas) and in Claude, you can see the simulator working right in the conversation. Test it and ask for changes in plain language ("the chart is cut off," "add a pause button"). Check the science: in one test of this request, the chart came out right, but the highlighted total of sick people said that the more people were vaccinated, the more people got sick.

Example of a fix in plain language
The total number of sick people is wrong: with 0% vaccinated it shows a negative number, and it goes up when vaccination goes up. The total should be the number of susceptible people at the start minus the number of susceptible people at the end. Fix it and reply again with the complete code.

This is for the error in the test above. Describe what is wrong and what you expected to see; you do not need to know how to program.

Another example: Mathematics
Create an interactive simulator in a single HTML file (HTML, CSS, and JavaScript together, no external libraries and no server), in English. Reply only with the complete code, in a single block, from <!DOCTYPE html> to </html>, without using Python and without creating files.

TOPIC: [trigonometric functions: f(x) = a + b·sin(c·x + d)]
FOR WHOM: [11th grade] students, subject [Mathematics].
WHAT THE STUDENT CAN CHANGE: [sliders for a, b, c, and d, and a button to switch between sine and cosine].
WHAT APPEARS ON SCREEN: [the graph of f(x) from −2π to 2π, the graph of sin(x) in gray for comparison, and the calculated amplitude, period, and range].
QUESTION THE SIMULATOR HELPS ANSWER: [what does each parameter do to the graph? Which one changes the period?]
EXTRAS: a "Reset" button, the x axis marked in multiples of π, large fonts for projecting in class.

To check the result: in sin(x + π/2), the graph moves to the left, and the horizontal shift is −π/2. With c = 2, the period is cut in half, from 2π to π.

Going further: agents

A chat answers a question. An agent receives a goal and works until it delivers: it opens pages, writes files, tests, and fixes. The chats you already use (ChatGPT, Gemini, Claude) are getting an agent mode, and Claude Code and Codex work with the files in a folder on your computer. There are also open options.
