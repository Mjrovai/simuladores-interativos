How the prediction works
Decode (tok/s): each generated token reads the active weights once from unified memory, so tok/s ≈ effective bandwidth ÷ active-weight bytes (MoE uses active params). Batching splits weights across streams until compute caps aggregate throughput.

Prompt / TTFT: compute-bound — TFLOPS × efficiency ÷ (2 × active params).

Memory: weights + KV cache (2 × layers × KV-heads × head-dim × dtype × tokens) + ~1.2 GB runtime overhead. If it doesn’t fit in usable RAM, the fraction that spills is read from SSD at the swap rate — that is what kills tokens/s.

Uncertainty: ±12% (±25% when swapping) covers runtime differences (llama.cpp vs MLX), quant overhead and thermals.
